# Supplementary figures

`make_figure_s1.py` through `make_figure_s5.py` generate supplementary Figures S1–S5 from cohort annotations, latent coordinates and analysis tables. Run them through:

```bash
bash scripts/reproduce_saved.sh INPUT_ZIP
```

Figures are written to `build/figures/supplementary/` as PDF and PNG files. Manuscript figure exports are provided in `manuscript/figures/`. Earlier component analyses are retained in `archive/figure_components/`; see the [reproduction guide](../../docs/reproduction.md) for figure and table coverage.
