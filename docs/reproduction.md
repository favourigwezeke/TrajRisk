# Reproduce the reported analyses

## Run the saved-model workflow

Install the Linux/Python 3.12 CPU environment in the [README](../README.md), obtain the [frozen inputs](frozen_inputs.md), then run:

```bash
bash scripts/reproduce_saved.sh build/downloads/TrajRisk_frozen_inputs.zip
```

The command validates publication assets and 135 input files, replays saved reference and external mouse/human models, checks recorded metric tolerances, and regenerates Figures S1–S5. Generated outputs are isolated under `build/`.

## Outputs

| Output under `build/frozen_replay/` | Contents |
| --- | --- |
| `reference_predictions.csv` | Scores for 6,582 reference hepatocytes. |
| `reference_scale_embeddings.npy` | Four 64-dimensional scale embeddings for each cell. |
| `external_mouse_predictions.csv` | Reference-KNN, W_self-only and seed scores. |
| `external_mouse_metrics.csv` | Cohort denominators, AUROC/AUPRC and bootstrap AUROC CIs. |
| `human_predictions.csv` | Primary and sensitivity human scores. |
| `human_donor_primary.csv`, `human_donor_sensitivity.csv` | Donor summaries. |
| `figure6e_distinct_gene_counts.csv` | Distinct-human-gene conservation counts. |
| `reproduction_report.json` | Environment, input provenance, outcomes and tolerances; complete bootstrap-enabled replay has 79 passing checks. |

Regenerated supplementary figures are written to `build/figures/supplementary/`. Inspect the report's `status` and individual `checks`; successful file validation alone does not establish numerical reproduction. Runtime depends on CPU and bootstrap evaluation. Available fonts can alter typography without changing values.

## GitHub Actions

The workflow checks out the commit selected for execution and downloads the specified **input** release. It does not switch source code to the input archive's older release tag. Run **Frozen reproduction** with input release `v0.1.0-rc1` to check the selected code against the unchanged archive. Its digest and packet manifest are verified before inference.
