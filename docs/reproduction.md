# Reproduce the study analyses

## Run

Install the Linux CPU environment described in the [README](../README.md), download the [model inputs](frozen_inputs.md), then run:

```bash
bash scripts/reproduce_saved.sh build/downloads/TrajRisk_frozen_inputs.zip
```

The command verifies the input files, loads the supplied checkpoints, computes reference and external-cohort scores, evaluates the associated metrics and generates Figures S1–S5. A complete run performs 79 numerical comparisons, including 1,000-resample mouse AUROC confidence intervals.

## Outputs

| File in `build/frozen_replay/` | Contents |
| --- | --- |
| `reference_predictions.csv` | Scores for 6,582 reference hepatocytes. |
| `reference_scale_embeddings.npy` | Four 64-dimensional embeddings per reference cell. |
| `external_mouse_predictions.csv` | Reference-KNN, W_self-only and seed scores for external mouse cohorts. |
| `external_mouse_metrics.csv` | Cohort sizes, AUROC, AUPRC and bootstrap AUROC confidence intervals. |
| `human_predictions.csv` | Human primary and sensitivity scores. |
| `human_donor_primary.csv`, `human_donor_sensitivity.csv` | Donor-level score summaries. |
| `figure6e_distinct_gene_counts.csv` | Distinct-human-gene significance counts by scale. |
| `reproduction_report.json` | Environment, input checksums, numerical comparisons and results. |

Figures S1–S5 are saved as PDF and PNG files in `build/figures/supplementary/`. Successful numerical validation is indicated by `status: passed` in the report. Runtime depends on CPU performance; available fonts can affect figure typography.

## Figure and table coverage

| Item | Provided analyses and files |
| --- | --- |
| Figures 1–7 | Manuscript PDF exports in `manuscript/figures/`. Composite assembly is separate from the saved-model command. |
| Figures S1–S5 | Generated by `scripts/figures/make_figure_s1.py` through `make_figure_s5.py`. |
| Table S1 | RF transition-statistics CSV. Refitting requires expression data and RF inputs. |
| Table S2 | Baseline and ablation CSVs, with reference-model metrics evaluated from saved predictions. Refitting the full comparison requires the training inputs. |
| Table S3 | External mouse treatment scores, AUROC/AUPRC and bootstrap intervals. Cdkn1a-expression labels and B1 refitting require expression data. |
| Table S4 | Human model scores and primary/sensitivity donor summaries. Signature discovery requires expression data. |
| Table S5 | Spatial result tables and plots from section/zone annotations. Historical spot-level rank tests are supplied as results. |
| Table S6 | Graph flux/amplification, bottleneck counts and Scale 3 quartile membership evaluated from saved graphs; remaining components supplied as CSVs. |
| Data S1–S5 | CSV files in `manuscript/data/`, with fields and units defined in the [data dictionary](data_dictionary.md). |

This command evaluates supplied model parameters and latent coordinates. Full raw-expression preprocessing, model retraining and main-figure composite assembly are separate analyses; their complete end-to-end execution is not covered by the saved-model test.

## Versioning

Code and model inputs are versioned separately. GitHub Actions evaluates the selected code commit using the input release specified by `release_tag`, normally `v0.1.0-rc1`. The input-archive digest and all manifest entries are verified before inference.
