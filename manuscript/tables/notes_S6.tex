Analyses use the frozen mouse TrajRisk model and its 421,477 directed edges on 6,582 Walesky cells. Top-flux edges are selected within each temporal scale. Source and target summaries count unique cells unless the column explicitly counts edges. Edge-removal analyses retain model weights and node features and rerun inference without retraining. Predicted TrajRisk scores, normalized pseudotime, and score changes are dimensionless; reported percentages use the indicated cell or edge population. Fisher and Mann--Whitney p values are nominal. RF, Random Forest; GNN, graph neural network; APAP, acetaminophen; SD, standard deviation.
